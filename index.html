📌 临考必记

物理常量和稳恒磁场模型速查

考前 10 分钟扫一遍：先记数字，再记三种对称性下的场强表达式。

一、基础物理常量（必背）

  • 质子质量$m_p = 1.673\times10^{-27}\,\text{kg}$≈ 1836 me
  • 电子质量$m_e = 9.11\times10^{-31}\,\text{kg}$≈ 0.511 MeV/c²
  • 普朗克常量$h = 6.626\times10^{-34}\,\text{J·s}$ℏ = h/2π ≈ 1.055×10⁻³⁴
  • 1 电子伏特$1\,\text{eV} = 1.602\times10^{-19}\,\text{J}$是能量单位，不是电压
  • 里伯德常数$R = 1.097\times10^{7}\,\text{m}^{-1}$氢原子光谱用
  • 真空介电常数$\varepsilon_0 = 8.85\times10^{-12}\,\text{F/m}$k = 1/(4πε₀) ≈ 9.0×10⁹
  • 真空磁导率$\mu_0 = 4\pi\times10^{-7}\,\text{H/m}$≈ 1.257×10⁻⁶
  • 真空光速$c = 3.00\times10^{8}\,\text{m/s}$c² = 1/(μ₀ε₀)

⚠️ 考试如果给 ε₀ 和 μ₀ 的具体数值（不让你背），就用 c = 1/√(μ₀ε₀) 推；如果让背，看清楚是相对值（εᵣ、μᵣ）还是绝对值。

二、稳恒磁场固定模型（必背）

核心思路：对称性 → 高斯面/安培环路 → 积分号外提常数

模型场强公式方向 / 说明
无限长直导线 $B = \dfrac{\mu_0 I}{2\pi r}$ 右手螺旋：拇指电流方向，四指环绕
长直螺线管内部 $B = \mu_0 n I$ n = 单位长度匝数；外部≈0
环形螺线管（螺绕环） $B = \dfrac{\mu_0 N I}{2\pi r}$ N 总匝数；r 环半径；环外≈0
圆电流圆心 $B = \dfrac{\mu_0 I}{2R}$ 轴线上 R 为圆电流半径
圆电流轴线上 $B = \dfrac{\mu_0 I R^2}{2(R^2 + x^2)^{3/2}}$ x 为圆心到该点距离
无限大均匀电流面 $B = \dfrac{\mu_0 i}{2}$ i = 单位宽度电流（面电流密度）
两平行长直导线间 $B = \dfrac{\mu_0 I_1}{2\pi r_1} \pm \dfrac{\mu_0 I_2}{2\pi r_2}$ 同向相吸，反向相斥

💡 速记口诀：直 1/r、螺 n 常、环 N/r、圆 1/R。注意区分"圆电流圆心"和"圆电流轴线"两个公式容易混！

三、考前 3 分钟自测清单

  1. ✅ 库仑定律 $F = kq_1q_2/r^2$，$k = 9.0\times10^9$
  2. ✅ 高斯定理 $\oint \vec E \cdot d\vec A = Q_{enc}/\varepsilon_0$
  3. ✅ 洛伦兹力 $F = qvB\sin\theta$（力垂直于 v-B 平面，不做功）
  4. ✅ 安培力 $F = BIl\sin\theta$（判断方向用左手定则）
  5. ✅ 法拉第 $\varepsilon = -N d\Phi_B/dt$（负号 = 楞次定律）
  6. ✅ 动生 $\varepsilon = Blv$（B⊥l⊥v 时）
  7. ✅ 位移电流 $I_d = \varepsilon_0 d\Phi_E/dt$（让安培环路在电容器处成立）
  8. ✅ 麦克斯韦方程组：两个高斯 + 两个环路（电生磁、磁生电）
