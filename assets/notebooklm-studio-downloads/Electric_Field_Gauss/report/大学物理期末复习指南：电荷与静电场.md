# 大学物理期末复习指南：电荷与静电场

本指南基于《大学物理》相关章节内容编写，旨在帮助学生深入理解电荷、库仑定律、电场强度及其计算、以及电偶极子等核心概念。

## 一、 核心概念与公式总结

### 1. 电荷的基本属性
*   **电荷守恒定律 (Principle of Conservation of Charge)：** 在一个孤立系统中，电荷的代数和保持不变。电荷既不能被创造，也不能被消灭，只能从一个物体转移到另一个物体。
*   **电荷量子化 (Quantization of Charge)：** 任何可观测的电荷量都是基本电荷单位 $e$ 的整数倍。
    *   基本电荷单位：$e = 1.602176634 \times 10^{-19} \text{ C}$。
    *   质子带电 $+e$，电子带电 $-e$。
*   **材料分类：**
    *   **导体 (Conductor)：** 电荷可在材料内部自由移动（如金属）。
    *   **绝缘体 (Insulator)：** 电荷几乎无法在材料内部移动。
    *   **半导体 (Semiconductor)：** 电性能介于导体和绝缘体之间。

### 2. 库仑定律 (Coulomb's Law)
描述两个静止点电荷之间的相互作用力：
$$F = k \frac{|q_1 q_2|}{r^2} = \frac{1}{4\pi\epsilon_0} \frac{|q_1 q_2|}{r^2}$$
*   **静电常数：** $k \approx 8.988 \times 10^9 \text{ N}\cdot\text{m}^2/\text{C}^2$（通常取 $9.0 \times 10^9$）。
*   **电常数 (真空介电常数)：** $\epsilon_0 = 8.854 \times 10^{-12} \text{ C}^2/\text{N}\cdot\text{m}^2$。
*   **特点：** 力沿着两点电荷的连线；同号电荷相斥，异号电荷相吸；符合牛顿第三定律。

### 3. 电场 (Electric Field)
电场是电荷对其周围空间性质的改变，它是电荷间相互作用的媒介。
*   **定义式：** $\vec{E} = \frac{\vec{F}_0}{q_0}$（$\vec{F}_0$ 是试验电荷 $q_0$ 受到的力）。
*   **点电荷的电场：** $\vec{E} = \frac{1}{4\pi\epsilon_0} \frac{q}{r^2} \hat{r}$。
    *   正电荷的电场方向径向向外；负电荷的电场方向径向向内。
*   **叠加原理 (Superposition)：** 空间某点的总电场等于所有源电荷在该点产生电场的矢量和：$\vec{E} = \vec{E}_1 + \vec{E}_2 + \vec{E}_3 + \dots$。

### 4. 连续电荷分布的电场计算
电荷分布在长度、表面或体积上时，使用密度表示：
*   **线电荷密度：** $\lambda = dQ/dL$ (单位：$\text{C/m}$)。
*   **面电荷密度：** $\sigma = dQ/dA$ (单位：$\text{C/m}^2$)。
*   **体电荷密度：** $\rho = dQ/dV$ (单位：$\text{C/m}^3$)。

**典型电场分布公式：**
| 电荷分布类型 | 场点位置 | 电场强度大小 ($E$) |
| :--- | :--- | :--- |
| **圆环电荷** (半径 $a$, 总电荷 $Q$) | 轴线上距离中心 $x$ 处 | $E = \frac{1}{4\pi\epsilon_0} \frac{Qx}{(x^2+a^2)^{3/2}}$ |
| **无限长直线电荷** (线密度 $\lambda$) | 距离直线 $r$ 处 | $E = \frac{\lambda}{2\pi\epsilon_0 r}$ |
| **无限大均匀带电平面** (面密度 $\sigma$) | 平面附近 | $E = \frac{\sigma}{2\epsilon_0}$ |
| **两块等量异号平行带电板之间** | 板间区域 | $E = \frac{\sigma}{\epsilon_0}$ |

### 5. 电偶极子 (Electric Dipole)
由一对等量异号电荷 ($+q$ 和 $-q$) 组成，间距为 $d$。
*   **电偶极矩：** $\vec{p} = q\vec{d}$（方向从负电荷指向正电荷）。
*   **在均匀外电场 $\vec{E}$ 中：**
    *   **合力：** 为零。
    *   **力矩：** $\vec{\tau} = \vec{p} \times \vec{E}$，大小为 $\tau = pE\sin\phi$。
    *   **电势能：** $U = -\vec{p} \cdot \vec{E} = -pE\cos\phi$。

## 二、 典型题型与易错点分析

### 1. 静电力的矢量叠加
*   **易错点：** 直接对力的数值进行加减，而忽略了方向。
*   **分析：** 必须先建立坐标系，将各个静电力分解为分量（$F_x, F_y$），分别求和后再合成总力。

### 2. 电场线与轨迹
*   **易错点：** 误认为带电粒子在电场中的运动轨迹一定沿电场线。
*   **分析：** 电场线在该点的切线方向是加速度的方向。只有当场线为直线且粒子初速度为零或初速度方向与场线平行时，轨迹才与场线重合。

### 3. 感应起电与极化
*   **典型题：** 为什么带电物体可以吸引不带电的轻小物体？
*   **分析：** 这是感应起电（针对导体）或极化（针对绝缘体）现象。靠近带电体的一侧会感应出异号电荷，因距离较近，吸引力大于远端同号电荷的排斥力，故整体表现为吸引。

### 4. 导体内部电场
*   **核心结论：** 在静电平衡状态下，导体内部任何一点的电场强度必须为零。否则，自由电荷将在电场力作用下继续移动。

## 三、 简答练习题 (Quiz)

1.  **问：** 当两个塑料棒都用毛皮擦过后，它们之间是吸引还是排斥？为什么？
    *   **答：** 排斥。因为它们获得了同种电荷（负电荷），同种电荷相互排斥。
2.  **问：** 电荷守恒是否意味着电荷不能被创造？请结合高能物理相互作用举例。
    *   **答：** 电荷守恒意味着封闭系统内的电荷代数和恒定。虽然可以产生粒子（如电子-正电子对的产生），但产生的正负电荷总量相等，系统总电荷保持不变。
3.  **问：** 为什么水是优良的溶剂？请从电学角度解释。
    *   **答：** 因为水分子是电偶极子。水分子的氧端带负电，氢端带正电。当盐（如 NaCl）放入水中，水分子的两端会分别吸引 $\text{Na}^+$ 和 $\text{Cl}^-$ 离子，使其溶于水中。
4.  **问：** 在计算两个球形电荷间的库仑力时，什么时候可以将它们视为点电荷？
    *   **答：** 当两个带电体的大小远小于它们之间的距离 $r$ 时。
5.  **问：** 如果一个试验电荷 $q_0$ 的电荷量增加一倍，该点的电场强度 $E$ 会改变吗？
    *   **答：** 不会。电场强度 $E = F_0/q_0$ 是空间本身的属性，由源电荷决定。虽然受力 $F_0$ 会增加一倍，但比值 $E$ 保持不变。

## 四、 深度探讨题 (Essay Prompts)

1.  **电磁力与万有引力的比较：** 请根据库仑定律和万有引力定律，探讨这两种基本相互作用的相似性与本质区别。为什么在微观粒子（如 $\alpha$ 粒子）之间重力可以忽略不计，而在天体运动中重力占主导地位？
2.  **电场概念的物理意义：** 解释为什么要引入“场”的概念来描述电荷间的相互作用，而不是沿用早期的“超距作用”观点。电场线这一图像化工具在理解复杂电场分布时有哪些优势和局限性？
3.  **感应起电的工业应用：** 结合静电喷涂（Electrostatic Painting）的原理，详细阐述感应电荷是如何在实际生产中提高效率并减少资源浪费的。

## 五、 核心术语表 (Glossary)

| 术语 | 英文对照 | 定义/说明 |
| :--- | :--- | :--- |
| **电势能** | Potential Energy | 电偶极子在电场中由于取向而具有的能量。 |
| **电偶极矩** | Electric Dipole Moment | 描述电偶极子强弱和方向的矢量，大小为 $qd$。 |
| **静电平衡** | Electrostatic Equilibrium | 导体内部电荷不再发生定向移动的状态。 |
| **诱导电荷** | Induced Charge | 由于受附近电荷影响而在物体表面产生的局部超额正电荷或负电荷。 |
| **极化** | Polarization | 绝缘体内部分子在电场作用下正负中心发生微小位移的现象。 |
| **叠加原理** | Superposition Principle | 多个电荷产生的总力或总电场等于各电荷单独产生的力或电场的矢量和。 |
| **试验电荷** | Test Charge | 放入电场中用于测量电场性质的、电荷量极小的点电荷。 |
| **源电荷** | Source Charge | 产生待研究电场的电荷分布。 |
