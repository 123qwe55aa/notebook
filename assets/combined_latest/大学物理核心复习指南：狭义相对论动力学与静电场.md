# 大学物理核心复习指南：狭义相对论动力学与静电场

本指南旨在总结狭义相对论动力学、静电场强度、静电场中的导体及电容相关核心概念，并提供练习题与术语表，助力深度复习。

---

## 第一部分：核心概念与公式汇总

### 1. 狭义相对论动力学 (Special Relativistic Dynamics)

在狭义相对论中，质量、动量和能量不再是独立无关的量，而是随运动状态变化的相对量。

| 物理量 | 公式 | 备注 |
| :--- | :--- | :--- |
| **相对论质量** | $m = \frac{m_0}{\sqrt{1-\beta^2}}$ | $\beta = v/c$；质量随速度增加而增大。 |
| **相对论动量** | $\vec{p} = m\vec{v} = \gamma m_0\vec{v}$ | 当 $v \ll c$ 时，退化为牛顿力学动量。 |
| **相对论力学基本方程** | $\vec{F} = \frac{\text{d}\vec{p}}{\text{d}t} = \frac{\text{d}(m\vec{v})}{\text{d}t}$ | 变质量系统的力学描述。 |
| **相对论动能** | $E_k = mc^2 - m_0c^2$ | 物体总能量与静止能量之差。 |
| **静止能量** | $E_0 = m_0c^2$ | 物体静止时所具有的能量。 |
| **总能量** | $E = E_k + E_0 = mc^2$ | 质能关系指出，质量与能量存在紧密联系。 |
| **能动量关系** | $E^2 = E_0^2 + p^2c^2$ | 描述总能量、静能与动量之间的勾股定理关系。 |

*   **光子特性：** 静止质量 $m_0 = 0$，速度恒为 $c$，能量 $E = h\nu$，动量 $p = E/c$。
*   **质能转换应用：**
    *   **核裂变：** 如 $^{235}_{92}\text{U}$ 裂变，1g 铀-235 释放能量约为 $8.5 \times 10^{10} \text{J}$。
    *   **轻核聚变：** 如氘核反应，释放能量约 $24 \text{MeV}$，需高温克服库仑排斥力。

### 2. 静电场强度与叠加 (Electric Field Intensity)

静电场是电荷周围存在的一种特殊物质，对放入其中的电荷有力的作用。

*   **库仑定律：** $\vec{F} = \frac{1}{4\pi\varepsilon_0} \frac{q_1q_2}{r^2} \vec{e}_r$，其中 $k = \frac{1}{4\pi\varepsilon_0} \approx 9 \times 10^9 \text{N}\cdot\text{m}^2/\text{C}^2$。
*   **电场强度定义：** $\vec{E} = \frac{\vec{F}}{q_0}$，单位为 $\text{N/C}$。
*   **场强计算方法：**
    *   **点电荷：** $E = \frac{1}{4\pi\varepsilon_0} \frac{Q}{r^2}$。
    *   **点电荷系（叠加）：** $\vec{E} = \sum \vec{E}_i$。
    *   **连续分布电荷：** $\text{d}\vec{E} = \frac{1}{4\pi\varepsilon_0} \frac{\text{d}q}{r^2} \vec{e}_r$。
        *   体电荷：$\text{d}q = \rho \text{d}V$
        *   面电荷：$\text{d}q = \sigma \text{d}S$
        *   线电荷：$\text{d}q = \lambda \text{d}l$
*   **电偶极子：** 电矩 $\vec{p} = q\vec{r}_0$。轴线延长线上场强 $E \approx \frac{1}{4\pi\varepsilon_0} \frac{2p}{x^3}$；中垂线上场强 $E \approx -\frac{1}{4\pi\varepsilon_0} \frac{p}{y^3}$。

### 3. 静电场中的导体 (Conductors in Static Electric Fields)

导体进入电场会发生**静电感应**，直至达到**静电平衡**。

*   **静电平衡条件：**
    1.  导体内部任何一点处的电场强度为零 ($\vec{E}_{in} = 0$)。
    2.  导体表面处电场强度方向垂直于表面。
    3.  导体是一个等势体，表面是等势面。
*   **电荷分布：**
    *   **实心导体：** 电荷只分布在导体外表面，内部无净电荷。
    *   **空腔导体：** 
        *   腔内无电荷时：电荷分布在外表面，内表面无电荷。
        *   腔内有电荷 $+q$ 时：内表面感应电荷 $-q$，外表面感应电荷 $+q$。
*   **尖端放电：** 导体表面电荷密度 $\sigma$ 与曲率半径有关。曲率半径越小（越尖锐），$\sigma$ 越大，附近场强越强，可导致空气电离。
*   **静电屏蔽：** 接地空腔导体可以屏蔽腔内、外电场的相互影响。

### 4. 电容与电容器 (Capacitance and Capacitors)

*   **孤立导体电容：** $C = \frac{Q}{V}$。球形孤立导体 $C = 4\pi\varepsilon_0 R$。
*   **电容器电容：** $C = \frac{Q}{U}$，其中 $U$ 为两极板电势差。
*   **平行板电容器：** $C = \frac{\varepsilon_0 S}{d}$；充有电介质时 $C = \frac{\varepsilon_r \varepsilon_0 S}{d}$。
*   **组合方式：**
    *   **并联：** $C = C_1 + C_2$
    *   **串联：** $\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2}$

## 第二部分：常见题型与易错点

1.  **连续带电体场强计算：** 
    *   *步骤：* 选择合适坐标系 -> 取电荷微元 $\text{d}q$ -> 写出分量表达式 $\text{d}E_x, \text{d}E_y$ -> 积分。
    *   *易错点：* 忽视对称性。例如圆环轴线上场强垂直分量相互抵消。
2.  **静电平衡判断：**
    *   判定电荷分布时，务必注意导体是否接地。接地导体电势为零，其外表面电荷可能发生迁移。
3.  **相对论动能与能量：**
    *   *易错点：* 习惯性使用 $\frac{1}{2}m v^2$。在高速（$v$ 接近 $c$）情况下，必须使用 $E_k = mc^2 - m_0 c^2$。

## 第三部分：简答练习题

1.  **为什么光子的静止质量必须为零？**
    *   *参考答案：* 根据相对论质量公式 $m = \frac{m_0}{\sqrt{1-\beta^2}}$，由于光速为 $c$，分母为零。要使质量 $m$ 具有物理意义，分子 $m_0$ 必须为零。
2.  **简述静电平衡状态下导体内部场强为零的原因。**
    *   *参考答案：* 若内部场强不为零，导体内的自由电子将在电场力作用下继续定向移动。只有当内部合场强为零时，电荷才停止宏观定向运动，达到平衡。
3.  **避雷针的工作原理是什么？**
    *   *参考答案：* 利用尖端放电原理。避雷针尖端曲率半径极小，感应电荷在此处密度极大，产生的强电场使周围空气电离，从而将云层电荷引入大地。

## 第四部分：深度探索思考题（论述题）

1.  **论述相对论质能关系 $E=mc^2$ 的物理意义及其对现代能源的影响。**
    *   *要点提示：* 讨论质量与能量的等价性，物质与运动的不可分割性；结合核裂变与核聚变中的质量亏损现象说明能量释放的来源。
2.  **分析心肌细胞电偶极矩与空间电势变化的关系。**
    *   *要点提示：* 心肌细胞受到刺激及恢复原状的过程中，会形成变化的电偶极矩，其在周围产生的电场会引起空间电势随时间变化。

## 第五部分：重要术语表

| 术语 | 定义/描述 |
| :--- | :--- |
| **静止质量 ($m_0$)** | 物体相对于惯性系静止时的质量。 |
| **库仑扭秤实验** | 用于测量电荷间作用力并验证库仑定律的物理实验。 |
| **试验电荷 ($q_0$)** | 电量足够小、体积足够小，放入电场中不影响原场分布的理想电荷。 |
| **电偶极矩 ($\vec{p}$)** | 描述电偶极子特征的矢量，方向从负电荷指向正电荷。 |
| **等势体** | 静电平衡时，整个导体内各点电势相等的物体。 |
| **电荷量子化** | 电荷是不连续的，任何电荷 $q$ 都是基元电荷 $e$ 的整数倍。 |
| **质量亏损 ($\Delta m$)** | 核反应前后静止质量的总和之差，对应释放的能量 $\Delta E$。 |
